Open Photos.

GitHub →

Context.

Cloud photo storage is expensive, slow, and often the only way people move pictures between a phone and a computer. Cross-platform transfers are especially messy — Android and macOS already fight each other, and getting a photo library off an iPhone onto a Windows machine is not much better.

Open Photos is a TartanHacks 2026 project I built with Kausthub, Opally, and Gabe. It is a phone app for moving images locally between a Windows computer and an iPhone — no cloud subscription, no upload wait, just a direct handoff.

The Problem.

Most “solutions” to photo transfer are cloud products. That means paying for storage you may not want, waiting on uploads, and hoping both devices are signed into the same account. We wanted a local, practical path for people who just need photos to exist on the other device.

Implementation.

The iPhone app talks to a local photo server. Once connected, the same files show up in a Windows PhotoLibrary folder — no cloud upload required.

What's Next.

The hackathon build focused on Windows ↔ iPhone. The roadmap from our pitch:

More compatibility — Windows → Android and a more complete Windows ↔ iOS path.

Google Drive, even when the computer is off — optional cloud fallback when a local machine is not available.

Labels and sorting — more metadata, a stronger sorting algorithm, and more creative ways to browse a transferred library.
